# 2026 浪人祭 Vagabond Festival 看團紀錄表

用跨舞台時間軸安排想看的演出，與團友比較行程，並找出衝堂時段。專案以單一 `index.html` 實作，使用 HTML、CSS 與原生 JavaScript，無須安裝前端套件或設定後端服務。

## 主要功能

- **跨舞台時間軸**：切換 DAY 1／DAY 2，依演出長度顯示場次，支援時間軸比例調整、樂團或曲風搜尋、突顯已選場次與團友熱門場次。
- **多人看團紀錄**：新增團友、設定頭像與顏色，切換目前成員並記錄各自想看的演出。
- **團友對照表**：依時間比較每位成員的選擇，可直接勾選場次，也能只顯示有人選取的演出。
- **個人跑台清單**：顯示依時間排序的行程、同場團友、相鄰演出的時間空檔與衝堂分析。
- **樂團資訊**：查看介紹與曲風，透過外部連結前往 YouTube 或 Spotify 搜尋試聽。
- **分享與匯出**：複製全團分享網址、匯出 CSV、下載個人 `.ics` 行事曆，或複製文字清單。
- **本機儲存**：成員與勾選紀錄儲存在瀏覽器 `localStorage`。

## 快速開始

### 取得專案

```sh
git clone https://github.com/idmakers/vagabond2026.git
cd vagabond2026
```

也可以從 GitHub 的 **Code → Download ZIP** 下載後解壓縮。

### 開啟網頁

可直接用瀏覽器開啟 `index.html`。若要穩定使用分享網址與固定來源的瀏覽器儲存，建議透過 HTTP 伺服器開啟。

若電腦已安裝 Python，可在專案目錄執行：

```sh
python -m http.server 8000
```

Windows 也可使用 `py -m http.server 8000`，接著開啟 <http://localhost:8000>。

頁面透過 CDN 載入 Tailwind CSS 3.4.17，並使用 Google Fonts 的 Noto Sans TC 與 JetBrains Mono；完整樣式與字型需要網路連線。

## 使用方式

1. 點選「新增團友」，輸入名稱並選擇頭像與顏色。
2. 點擊上方成員標籤，切換目前記錄的人員。
3. 選擇日期，在「2D 時間軸總表」點擊演出方塊，即可勾選或取消；點擊右上角 `ⓘ` 查看樂團資訊。
4. 開啟「多人看團對照表」，比較團友行程，或直接替成員調整勾選。
5. 開啟「個人跑台清單與衝堂」，查看行程與重疊時段，再依需要調整場次。
6. 完成後複製分享網址，或匯出報表、行事曆與文字清單。

### 分享與資料保存

「複製全團分享網址」會把當下所有成員與勾選紀錄編碼在網址的 `#share=...` 片段中。對方開啟同一個已部署網站的分享網址後，即可匯入這份紀錄；若已有成員資料，頁面會先詢問是否取代。

- 分享內容是建立網址當下的快照，後續修改須重新產生分享網址。
- 多人功能在同一份頁面資料中管理多位成員，沒有伺服器端帳號或即時同步。
- 分享網址包含成員名稱與選團資料，採 Base64 編碼，並未加密。
- 跨裝置分享時，請使用雙方都能存取的網站網址；`localhost` 僅適用於各自的電腦。
- 紀錄與瀏覽器及網站來源綁定；更換瀏覽器、網域或連接埠，可能會看到不同資料。
- 清除網站資料或全部紀錄會移除本機資料；可先保留分享網址作為匯入用快照。

### 匯出範圍

| 功能 | 匯出內容 |
| --- | --- |
| CSV 報表 | 兩天全部演出及所有成員的勾選狀態，不受畫面日期或「僅顯示有人勾選」篩選影響 |
| `.ics` 行事曆 | 目前成員兩天所有已選演出 |
| 文字清單 | 目前成員的已選演出，依 DAY 1／DAY 2 分組 |

行事曆事件目前未指定時區，匯入時請確認時間設定符合活動所在地時間。

## 專案結構與維護

```text
vagabond2026/
├── index.html   # 頁面結構、樣式、演出資料與互動邏輯
└── README.md    # 專案與使用說明
```

主要設定皆位於 `index.html` 的內嵌 JavaScript：

| 設定 | 用途 |
| --- | --- |
| `STAGES` | 舞台名稱、識別碼與顏色 |
| `SHOWS` | 演出日期分組、舞台、起迄時間、樂團與介紹 |
| `USER_COLORS`／`USER_AVATARS` | 成員可選的顏色與頭像 |
| `STORAGE_KEY` | 本機儲存鍵值，目前為 `vagabond2026_schedule_v1` |

修改演出資料時，請維持場次 `id` 唯一，並讓 `stage` 對應 `STAGES` 的識別碼。既有勾選與分享資料依場次 `id` 對應，任意更換會影響舊紀錄。

頁面目前以 2026/11/07、2026/11/08 為兩天日期；若調整活動日期，請同時更新畫面標籤與 `.ics` 匯出邏輯中的日期。

## 部署

將 `index.html` 放到支援靜態檔案的網站主機即可使用，無須建置步驟、資料庫或環境變數。若使用 GitHub Pages，可在儲存庫 **Settings → Pages** 設定從 `main` 分支的根目錄發布，並以 GitHub 顯示的實際網址存取與分享。
